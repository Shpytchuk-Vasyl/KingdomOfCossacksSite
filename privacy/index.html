Коротко

Гра не збирає, не зберігає й не передає жодних персональних даних. Немає облікових записів, реклами, аналітики, трекерів і сторонніх SDK. Усе, що гра зберігає, лежить лише на вашому пристрої.

Які дані збираються

Жодних. Гра не просить імені, електронної пошти, номера телефону, геолокації, контактів, фото чи будь-яких інших даних і не має способу їх отримати.

Що гра зберігає на пристрої

  • Збереження гри (стан міста, кампанії, вільної гри) і налаштування (мова, гучність, графіка). Вони лежать у теці даних гри на вашому пристрої й видаляються разом із грою.
  • Гра не робить резервних копій у хмару і не надсилає збереження нікуди.

Мережа

Гра працює без інтернету. Режим «Мережева гра» дозволяє грати з іншими гравцями в одній локальній мережі (наприклад, в одному Wi-Fi). У цьому режимі гра:

  • розсилає в локальну мережу короткі повідомлення, щоб інші пристрої побачили відкриту гру (широкомовні й multicast-пакети);
  • обмінюється з пристроями інших гравців лише ігровими командами (куди йти, що будувати) і назвою гри, яку задає той, хто її створив.

Жодне з цих повідомлень не виходить за межі локальної мережі й не надсилається на сервери розробника чи третіх осіб. Серверів у гри немає.

Дозволи, які просить гра

Дозвіл Навіщо
Інтернет (INTERNET) обмін ігровими командами між пристроями в локальній мережі
Стан мережі й Wi-Fi (ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE) зрозуміти, чи є локальна мережа, щоб показати «Мережеву гру»
Multicast у Wi-Fi (CHANGE_WIFI_MULTICAST_STATE) щоб пристрої в одній мережі могли знайти відкриту гру
Локальна мережа (iOS) те саме; iOS питає про це окремим вікном

Жоден дозвіл не використовується для збору даних.

Реклама, аналітика, треті сторони

У грі немає реклами, аналітики, систем збору помилок, соціальних мереж і будь-яких сторонніх SDK. Якщо ви встановили гру з магазину (Google Play, App Store, Microsoft Store, AppGallery, Steam), магазин може збирати власну статистику встановлень і помилок відповідно до своєї політики конфіденційності; розробник бачить лише знеособлені підсумки, які надає магазин.

Діти

Гра не збирає даних і від дітей також. Вона не містить реклами, покупок і спілкування з незнайомими людьми: мережева гра можлива лише з пристроями в тій самій локальній мережі.

Ваші права

Оскільки гра не збирає персональних даних, розробник не має даних, які можна було б надати, виправити чи видалити. Щоб видалити все, що гра зберігає на пристрої, достатньо видалити гру. З будь-яких питань пишіть на shpakstudio.ua@gmail.com.

Зміни політики

Нова версія публікується на цій сторінці із зазначенням дати. Якщо гра колись почне збирати дані (наприклад, для онлайн-гри через сервер або покупок), це буде описано тут до того, як така версія вийде.

In short

The game does not collect, store or transmit any personal data. There are no accounts, ads, analytics, trackers or third-party SDKs. Everything the game stores stays on your device.

What data is collected

None. The game never asks for your name, e-mail, phone number, location, contacts, photos or any other data, and has no means to obtain them.

What the game stores on your device

  • Save games (your town, campaign and free-play progress) and settings (language, volume, graphics). They live in the game's data folder on your device and are removed when you uninstall the game.
  • The game makes no cloud backups and sends save games nowhere.

Network

The game works offline. The "Network game" mode lets you play with other people on the same local network (for example, the same Wi-Fi). In this mode the game:

  • sends short messages to the local network so that other devices can see an open game (broadcast and multicast packets);
  • exchanges only game commands (where to go, what to build) and the game name chosen by the host with the other players' devices.

None of these messages leave the local network, and none are sent to the developer or to any third party. The game has no servers.

Permissions the game requests

Permission Purpose
Internet (INTERNET) exchanging game commands between devices on the local network
Network and Wi-Fi state (ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE) detecting whether a local network is available so the "Network game" option can be shown
Wi-Fi multicast (CHANGE_WIFI_MULTICAST_STATE) letting devices on the same network discover an open game
Local Network (iOS) the same; iOS asks for it with its own prompt

No permission is used to collect data.

Advertising, analytics, third parties

The game contains no advertising, analytics, crash reporting, social network integration or any third-party SDK. If you installed the game from a store (Google Play, App Store, Microsoft Store, AppGallery, Steam), that store may collect its own install and crash statistics under its own privacy policy; the developer only sees the anonymous aggregates the store provides.

Children

The game collects no data from anyone, children included. It has no ads, no purchases and no contact with strangers: network play is only possible with devices on the same local network.

Your rights

Because the game collects no personal data, the developer holds no data to provide, correct or delete. To remove everything the game stores on your device, uninstall the game. For any question write to shpakstudio.ua@gmail.com.

Changes to this policy

A new version is published on this page with its date. Should the game ever start collecting data (for example for server-based online play or purchases), it will be described here before such a version is released.
